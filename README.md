This Power BI dashboard provides an end-to-end analysis of bicycle sales data using a mix of basic and advanced DAX measures.
It is designed to help users quickly understand sales trends, customer behavior, and performance across regions and time periods.

Key features include:

* Interactive visuals to filter and explore sales by product category, region, and salesperson.
* Time intelligence (YTD, MTD, QTD) using advanced DAX for dynamic period comparisons.
* Custom KPIs highlighting revenue, profit margins, units sold, and target achievement.
* Drill-through pages for detailed customer and product analysis.
* Advanced DAX patterns for rolling averages, ranking, and cohort segmentation.

This dashboard is a practical example of combining strong data modeling with clear storytelling to support better sales decisions.
